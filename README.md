# Nithish K – personal site

Static site, no build step. Open `index.html` in a browser to preview.

## Add a new achievement
Edit `data.js`, copy any `{ ... }` block, change the fields, save. Entries sort themselves by `date`.

## Publish an update
```
git add -A
git commit -m "Add <achievement>"
git push
```
GitHub Pages redeploys within a minute or two.
